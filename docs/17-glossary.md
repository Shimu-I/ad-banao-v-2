# Glossary

Terms used in these documents.

| Term | Meaning |
| --- | --- |
| Ad scene or layers | The editable description of an ad: a list of photo, text, button and logo layers on a canvas |
| Grounded | Generated only from facts the user entered, and checked against them |
| Fact checker | Code that finds numbers, currencies, contacts and claims in generated text that the user never entered |
| Content hash | A fingerprint of an ad's content. Approval is valid only while it matches |
| Verified, Issue found, Cannot verify | The three possible results of a check. "Cannot verify" means there was not enough evidence |
| Archive | Hide an item without deleting it, so ads that use it keep working |
| ADR | Architecture decision record: a short note on why a technical choice was made |
| CI | Continuous integration: automatic checks on every pull request |
| Migration | A versioned change to the database structure |
| venv | A Python virtual environment: an isolated folder of packages for one project |
| SDLC | Software development life cycle: the phases software goes through from idea to maintenance |
| OCR | Optical character recognition: reading text from an image |
| Raqm | A text layout engine that lets Pillow shape complex scripts like Bangla correctly |
